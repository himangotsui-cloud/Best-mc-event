# Permissions

- cpvpevent.* — all permissions
- cpvpevent.admin — full admin command access (default: op)
- cpvpevent.revive — use /revive as non-op when enabled (default: true)
- cpvpevent.staffchat — use /staffchat (default: op)
- cpvpevent.eventsettings — /eventsettings, /eventools (default: op)
- cpvpevent.party — /party (default: true)
- cpvpevent.party.admin — disband/resetall parties (default: op)
- cpvpevent.regen — /regen (default: op)
- cpvpevent.tpspawn — /tpspawn (default: true)
